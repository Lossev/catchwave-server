# CatchWave server

Маленький сервер для VPS: одна закрытая папка с вашими аудиофайлами, которую может открыть только ваше приложение CatchWave для iPhone. Один файл на Python 3, без сторонних пакетов.

*A tiny self-hosted server for the CatchWave iPhone app: one private folder with your own audio files on your VPS, served over TLS to your phone only. Single Python 3 file, no dependencies. Run `sudo bash install.sh` on Ubuntu or Debian; it prints the address, port and a QR code to enter in the app.*

Приложение не содержит и не раздаёт никаких аудиозаписей: оно показывает только те файлы, которые вы сами положили на свой сервер. Кладите туда только то, на что у вас есть права.

Вопросы и ошибки — в [Issues](https://github.com/Lossev/catchwave-server/issues). [Политика конфиденциальности приложения](PRIVACY.md).

## Установка (Ubuntu, Debian, Kali)

Зайдите на VPS по SSH и выполните:

```bash
git clone https://github.com/Lossev/catchwave-server.git
```

```bash
sudo bash catchwave-server/install.sh
```

Установщик спросит пароль для приложения (минимум 8 символов). Если запускать его без терминала (например, одной командой через `ssh`), он придумает пароль сам и покажет один раз.

Другой порт или адрес: `sudo CATCHWAVE_PORT=9443 CATCHWAVE_HOST=1.2.3.4 bash install.sh`.

Установщик:

- создаёт системного пользователя `catchwave` и папку `/srv/catchwave/music` с правами `2770` — другим пользователям сервера она недоступна;
- сохраняет в `/etc/catchwave` производный ключ от пароля (сам пароль не хранится) и собственный TLS-сертификат;
- ставит службу systemd `catchwave` с автозапуском и открывает порт в `ufw`, если он включён;
- печатает адрес, порт и QR-код для приложения.

В приложении вводятся адрес, порт и пароль — либо сканируется QR-код, тогда пароль не нужен.

Показать адрес, порт и QR-код ещё раз: `sudo bash install.sh show`. Сменить пароль: `sudo bash install.sh password` (после этого в приложении нужно подключиться заново). Повторный запуск установщика обновляет сервер, пароль и сертификат остаются прежними.

## Как положить файлы

Установщик добавляет вашего пользователя в группу `catchwave` (нужно перезайти по SSH), после этого:

```bash
scp -r ~/Music/МоиТреки user@ВАШ_VPS:/srv/catchwave/music/
```

Подпапки сохраняются. Сервер отдаёт только `mp3, m4a, aac, wav, aif, aiff, flac, caf`; скрытые файлы и ссылки наружу папки игнорируются.

## Защита

- Весь трафик идёт по TLS. Сертификат самоподписанный, поэтому приложение запоминает его отпечаток SHA-256 и дальше сверяет его при каждом соединении.
- Пароль по сети не передаётся. При входе сервер доказывает, что знает пароль, подписью, в которую входит отпечаток его сертификата, — подменённый сервер эту проверку не пройдёт.
- Из пароля и отпечатка выводится токен. Каждый запрос, кроме `/api/hello`, должен нести `Authorization: Bearer <токен>`, иначе сервер отвечает `401`.
- Стойкость держится на пароле: `/api/hello` позволяет подбирать его перебором, поэтому пароль должен быть длинным и неочевидным.
- Служба работает от отдельного пользователя без прав, файловая система для неё доступна только на чтение.

## API

| Запрос | Ответ |
|---|---|
| `GET /api/hello?nonce=<hex>` | `{"salt", "iterations", "proof"}` — без токена |
| `GET /api/ping` | `{"ok": true, "name": "CatchWave", "version": "2"}` |
| `GET /api/tracks` | `{"tracks": [{"path": "Альбом/трек.mp3", "size": 123, "modified": 1700000000}]}` |
| `GET /api/file/<path>` | файл; поддерживает `Range` и `If-Range` для докачки |

Журнал: `journalctl -u catchwave -f`.
